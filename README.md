# Python Fundamentals
## Week 1 and 2, AI Engineering learning plan.

* `hello.py`: My first Python code.
* `about_me.py`: A small program which prints details about myself.
* `calculator.py`: Very basic and simple calculator without error handling.
* `loops.py`: A simple program where I learned to use basic loop functions.
* `safe_calc.py`: A simplified calculator which adds, subtracts, multiplies and divides 2 numbers with error handling.
* `guess.py`: A simple guess the number program using while loops.
* `functions.py`: A small program where I learned about the basics of functions.
* `bank.py`:  A bank simulator created using basic loops, ifs, functions with error handling.
* `classic_problems.py`: Classic interview problems which are FizzBuzz, Prime numbers and Sum of the Digits.
* `converter.py`: A unit converter program made using loops, ifs, functions with error handling.
* `grades.py`: A very simple program to find what grade you got using your score.
* `guess_v2.py`: A more advanced version of the guess the number with loops, ifs, functions with error handling.
* `rps.py`: An advanced program to play rock, paper, scissors with loops, if conditions, functions and error handling.

### How to Run
To run any of these programs in your codebase just download the repo and use the terminal to run the following command given below with its file name
```
python3 file_name.py
```
